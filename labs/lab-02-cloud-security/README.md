# Lab 02 — Cloud Security Architecture

**Author:** [mari-2215](https://github.com/mari-2215)  
**Status:** Planned

## Objective

Build a multi-tier Packet Tracer environment representing public, application, database, and management zones. Demonstrate controlled north-south and east-west traffic, static publication of a web service, protected database access, and restricted administration through a bastion-style host.

## Planned evidence

- topology and addressing plan;
- permitted client-to-web traffic;
- permitted application-to-database traffic on the required service port;
- denied web-to-database traffic;
- restricted SSH from the management origin;
- NAT and ACL counters;
- AWS and Azure control mapping.
