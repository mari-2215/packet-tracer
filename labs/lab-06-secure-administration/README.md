# Lab 06 — Secure Administration

**Author:** [mari-2215](https://github.com/mari-2215)  
**Status:** Planned

## Objective

Build an isolated management plane with SSH, AAA/RADIUS, role-oriented access, management-source restrictions, and a controlled fallback test. The lab will focus on identity and administrative access rather than ordinary data-plane reachability.

## Planned evidence

- dedicated management VLAN;
- SSH-only VTY configuration;
- authorized administrator login;
- unauthorized user-zone attempt;
- AAA server success;
- controlled AAA failure and local fallback;
- audit and cloud-IAM mapping.
