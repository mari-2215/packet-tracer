# Lab 03 — Incident Detection and Containment

**Author:** [mari-2215](https://github.com/mari-2215)  
**Status:** Planned

## Objective

Create a controlled defensive incident in which an external test host generates unauthorized traffic toward an internal service. Record the baseline, identify the source in ACL counters or simulated logs, add a specific containment rule, verify the block, and document recovery.

## Planned evidence

- normal baseline traffic;
- suspicious source and destination;
- pre-containment counters/logs;
- containment change;
- post-containment deny evidence;
- service availability for legitimate clients;
- incident timeline and lessons learned.
