# Lab 05 — Resilient Branch Routing

**Author:** [mari-2215](https://github.com/mari-2215)  
**Status:** Planned

## Objective

Connect a headquarters network and multiple branches with OSPF. Establish an intended primary path, capture the stable routing state, fail a link, observe convergence, and demonstrate service recovery through an alternate path.

## Planned evidence

- OSPF neighbors;
- normal route table and traceroute;
- explicit link failure event;
- convergence evidence in Simulation Mode;
- recovered route table and traceroute;
- management-plane ACL validation.
